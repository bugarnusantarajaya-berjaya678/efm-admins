# EFM V2 — Admin Dashboard

Admin dashboard internal untuk CV. Bugar Nusantara Jaya (Essential Fitness Management) — mengelola 3 pilar bisnis: Private Program (PP), B2B Corporate & Property, dan Event Management.

## URL

- **Production:** https://efm-admins.vercel.app
- **Repo:** https://github.com/bugarnusantarajaya-berjaya678/efm-admins

## Stack

- Frontend: React 18 + Vite + Tailwind CSS v3
- Routing: React Router v6
- State: React local state + localStorage
- Hosting: Vercel
